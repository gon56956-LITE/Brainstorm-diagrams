# Naturalcases

Natural-language source examples and expected structured drafts are grouped by diagram type.

- `fishbone/`: natural-language examples for Codex-assisted fishbone drafting.
- `fault-tree/`: natural-language examples for Codex-assisted fault-tree drafting.
- `exclusion-tree/`: natural-language examples for Codex-assisted exclusion-tree drafting.
- `two-by-two-matrix/`: natural-language examples for Codex-assisted two-axis prioritization and comparison matrices.
- `roadmap-timeline/`: natural-language examples for Codex-assisted roadmap and milestone timeline drafting.
- `fmea-table/`: natural-language examples for Codex-assisted simplified FMEA table drafting.

Future diagram types should add their own subdirectory instead of mixing files at this level.
