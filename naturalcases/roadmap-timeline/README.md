# Roadmap Timeline Naturalcases

These examples protect Codex-assisted natural-language drafting for `diagram_type: roadmap_timeline`.

- Use `swimlane_roadmap` when the source describes multiple parallel tracks such as teams, workstreams, models, modules, or regions.
- Use `milestone_timeline` when the source describes one sequence of dated milestones, gates, phases, or launch events.
- Keep output single-language unless the user explicitly requests bilingual content.
- Keep raw source text and expected Markdown here; generated SVG/PNG files do not belong in this directory.
