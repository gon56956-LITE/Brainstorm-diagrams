# Fault Tree Stresscases

Optional dense fault tree diagrams for manual visual review.

- `full-stress.json` -> `full-stress.svg`
- `nested-gates.json` -> `nested-gates.svg`
- `eight-branches.json` -> `eight-branches.svg`

These cases intentionally cover the MVP limits and nested gate behavior: eight first-level events, four basic events per first-level event, mixed AND/OR gates, nested intermediate events, long basic event labels, and long event detail panels.
