# Reliability Qualification Timeline

Goal: Track the sequence of reliability qualification milestones for an optical module before release.

## Milestones

| ID | Name | Date | Type | Owner | Status | Output |
|---|---|---|---|---|---|---|
| R1 | Qualification Kickoff | 2025-04-07 | start | Reliability | completed | Confirm stress plan, sample size, and pass criteria |
| R2 | Sample Readiness | 2025-05-12 | milestone | NPI | completed | Release screened samples and golden units |
| R3 | Test Plan Review | 2025-06-02 | review | Quality | completed | Approve aging, thermal cycling, damp heat, and ESD scope |
| R4 | High-Temp Aging Start | 2025-07-10 | key_milestone | Reliability | in_progress | Start long-duration high-temperature operating life test |
| R5 | Interim Data Review | 2025-08-21 | review | Engineering | planned | Check power drift, BER trend, and temperature margin |
| R6 | Failure Analysis Gate | 2025-10-03 | decision | FA Team | planned | Decide whether observed failures require corrective action |
| R7 | Qualification Complete | 2025-11-14 | key_milestone | Quality | planned | Complete required reliability stress reports |
| R8 | Release Readiness | 2025-12-19 | launch | Program | planned | Approve production release with documented residual risks |
